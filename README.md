## 📌 Features

- **Customer Side**:
  - Online table reservation

  - User registration, login, and profile management
- **Admin & Staff Side**:
  - Reservation management
  - POS & table billing system
  - Menu and staff account management

## 🛠 Tech Stack

- **Backend**: PHP
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript, Bootstrap

---

## 🚀 Getting Started

1. Place the project folder into your web server directory (e.g. `xampp/htdocs/`).
2. Start Apache and MySQL services (via XAMPP or equivalent).
3. Import `restaurantDB.txt` into MySQL or navigate to `index.php` in your browser for automatic database setup.
4. Open `customerSide/home/home.php` in your browser.
